# 1-2 keilkill 批处理

编译辅助工具，一键清理 Keil 工程生成的编译中间文件（`Objects/`、`Listings/`、`.o`、`.crf`、`.hex` 等），让工程目录只保留源码，恢复干净状态。

## 文件

| 文件 | 说明 |
|------|------|
| `keilkill.bat` | Windows 批处理脚本，双击运行即可清理 |

## 使用方法

1. 把 `keilkill.bat` 放到 Keil 工程目录下
2. 双击运行，即可删除该目录下所有编译产物
3. 如需清理子目录，可将脚本放在工程根目录并保持足够删除权限

## 作用

- 编译产物累积会占用大量磁盘空间
- 提交到 Git / 分享给他人之前，先运行它能让工程更清爽（编译产物本就不该进版本控制）
