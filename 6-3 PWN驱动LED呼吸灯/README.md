# 6-3 PWM 驱动 LED 呼吸灯

PWM 实验：用 PWM 占空比连续变化驱动 LED 亮度渐亮渐弱，形成呼吸灯效果。

## 功能

- 定时器输出 PWM（脉宽调制）信号
- 通过改变比较值 `PWM_SetCompare` 调节占空比
- 占空比 0→100% 渐亮、100%→0 渐暗，循环形成呼吸效果

## 涉及知识点

- 定时器 **PWM 输出模式**
- PWM 占空比与亮度的关系
- 改变比较寄存器（CCR）实时调节占空比

## 源文件

| 文件 | 说明 |
|------|------|
| `User/main.c` | 主循环调节占空比 |
| `User/PWM.c/h` | PWM 初始化与占空比设置 |

## 核心接口

| 函数 | 说明 |
|------|------|
| `PWM_Init()` | 初始化定时器 PWM 输出 |
| `PWM_SetCompare1()` | 设置通道 1 比较值（0~100） |

## 源码大致逻辑

```c
while (1) {
    for (i = 0; i <= 100; i++) { PWM_SetCompare1(i); Delay_ms(10); }       // 渐亮
    for (i = 0; i <= 100; i++) { PWM_SetCompare1(100 - i); Delay_ms(10); } // 渐暗
}
```

## 接线

| LED(经限流电阻) | STM32 |
|----------------|-------|
| 正极 | PWM 输出引脚（`PWM.h` 配置） |
| 负极 | GND |

> 目录名 "PWN" 为原工程命名笔误，实为 PWM。
