# STM32 学习项目

基于 **STM32F103C8T6**（标准外设库）的嵌入式学习记录，使用 **Keil MDK-ARM** 开发。

本项目是我从小到大跟学 STM32 的完整源码记录，按学习进度分目录存放，每个目录是一个独立的 Keil 工程。

## 开发环境

| 项目 | 说明 |
|------|------|
| 芯片 | STM32F103C8T6（Cortex-M3） |
| 库 | 标准外设库（STM32F10x Standard Peripheral Library） |
| IDE | Keil MDK-ARM |
| 烧录 | ST-Link / 串口 ISP |

## 目录说明

| 目录 | 内容 |
|------|------|
| `1-2 ~ 1-4` | 环境与基础模块：keilkill 批处理、Delay 延时、OLED 驱动 |
| `2-1` | STM32 空工程模板（点灯之前的框架） |
| `3-1 ~ 3-5` | GPIO 基础：LED 闪烁 / 流水灯 / 蜂鸣器 / 按键 / 光敏传感 |
| `4-1` | OLED 显示屏驱动 |
| `5-1 ~ 5-2` | 外部中断 / 计数器：红外传感器计次、旋转编码器计次 |
| `6-1 ~ 6-5` | 定时器 & PWM：定时中断 / 外部时钟 / 呼吸灯 / 舵机 / 直流电机 |
| `7-1 ~ 7-2` | ADC 模数转换：单通道 / 多通道 |
| `9-1 ~ 9-2` | 串口 USART：发送 / 收发 |

## 每个工程的标准结构

以 Keil 工程为例，每个工程目录下通常包含：

| 目录 | 说明 |
|------|------|
| `User/`   | 用户源码（`main.c` 等） |
| `Library/`| 标准外设库源文件 |
| `Start/`  | 启动文件、内核文件、时钟配置 |
| `System/` | 系统模块（部分工程） |

调试生成物（`Objects/`、`Listings/`、`DebugConfig/` 等）已通过 `.gitignore` 排除，不纳入版本管理。

## 使用方法

1. 用 Keil MDK-ARM 打开任一工程目录下的 `Project.uvprojx`
2. 连接 STM32F103C8T6 开发板（ST-Link）
3. 编译并下载运行

## 学习建议

按目录顺序从 `1-2` 开始，循序渐进理解 GPIO、定时器、中断、PWM、ADC、串口等外设的使用。
