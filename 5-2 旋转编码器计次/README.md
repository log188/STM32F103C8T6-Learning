# 5-2 旋转编码器计次

正交编码器实验：读取旋转编码器转向与步数，OLED 实时显示累加值。

## 功能

- 旋转编码器输出正交信号（A/B 相）
- 使用定时器编码器模式计数
- 顺时针旋转累加、逆时针旋转递减
- OLED 显示当前累计值 `Num:`（可正可负）

## 涉及知识点

- 定时器 **编码器接口模式**（Encoder Mode）
- 定时器配置与计数寄存器读取
- 有符号累加显示

## 源文件

| 文件 | 说明 |
|------|------|
| `User/main.c` | 主逻辑与显示 |
| `User/Encoder.c/h` | 编码器驱动 |

## 核心接口

| 函数 | 说明 |
|------|------|
| `Encoder_Init()` | 初始化编码器模式的定时器 |
| `Encoder_Get()` | 返回本次旋转的步数（带方向） |

## 源码大致逻辑

```c
while (1) {
    Num += Encoder_Get();        // 累加旋转步数
    OLED_ShowSignedNum(1, 5, Num, 5);
    Delay_ms(50);
}
```

## 接线

| 编码器 | STM32 |
|--------|-------|
| A 相 | `Encoder.h` 配置引脚（TIM 通道） |
| B 相 | `Encoder.h` 配置引脚 |
| VCC / GND | 3.3V / GND |

> 用定时器编码器模式可硬件自动识别正反转，CPU 无需干预。
