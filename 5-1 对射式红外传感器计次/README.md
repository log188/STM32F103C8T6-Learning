# 5-1 对射式红外传感器计次

外部中断实验：对射式红外传感器每遮挡一次，触发外部中断计数，OLED 实时显示。

## 功能

- 对射式红外传感器输出信号经外部中断触发
- 每检测到一次遮挡，计数 +1
- OLED 显示 `Count:` 当前计数值

## 涉及知识点

- **外部中断（EXTI）** 的使用
- GPIO 输入模式 + 外部中断配置
- 中断服务函数中自增计数
- OLED 实时刷新数字

## 源文件

| 文件 | 说明 |
|------|------|
| `User/main.c` | 主逻辑与显示 |
| `User/CountSensor.c/h` | 传感器初始化与计数读取 |
| `System/Delay.c/h` | 延时 |

## 核心接口

| 函数 | 说明 |
|------|------|
| `CountSensor_Init()` | 初始化传感器引脚与外部中断 |
| `CountSensor_Get()` | 返回当前计数值 |

## 接线

| 红外模块 | STM32 |
|---------|-------|
| 信号输出 D0 | `CountSensor.h` 配置引脚 |
| VCC | 3.3V / 5V |
| GND | GND |

> 对射式红外：发射端与接收端对置，物体穿过时输出电平变化，触发中断。
