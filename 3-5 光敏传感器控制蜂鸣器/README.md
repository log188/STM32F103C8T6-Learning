# 3-5 光敏传感器控制蜂鸣器

传感器输入实验：光照变化控制蜂鸣器启停，演示简单的外部输入判断。

## 功能

- 封装 `LightSensor_Get()` 读取光敏传感器模块的数字量输出
- 循环判断：
  - 光线被遮挡（返回 1）：`Buzzer_ON()`
  - 光线充足（返回 0）：`Buzzer_OFF()`

## 涉及知识点

- GPIO 输入读取传感器数字信号
- 简单的条件判断控制输出
- 模块化封装传感器与执行器

## 源文件

| 文件 | 说明 |
|------|------|
| `User/main.c` | 主逻辑 |
| `User/LightSensor.c/h` | 光敏传感器读取 |
| `User/Buzzer.c/h` | 蜂鸣器控制 |
| `System/Delay.c/h` | 延时 |

## 接线

| 模块 | STM32 |
|------|-------|
| 光敏传感器模块 D0 | `LightSensor.h` 配置引脚 |
| 蜂鸣器 I/O | `Buzzer.h` 配置引脚 |
| VCC / GND | 3.3V / GND |

> 光敏电阻模块有数字量输出（D0）和模拟量输出（A0），本实验用 D0 数字输出。
