# 1-3 Delay 延时函数模块

自封装的延时模块，基于系统时钟（SysTick）实现精确毫秒延时，供后续所有工程复用。

## 文件

| 文件 | 说明 |
|------|------|
| `Delay.c` | 延时函数实现 |
| `Delay.h` | 延时函数声明 |

## 接口

| 函数 | 说明 |
|------|------|
| `Delay_ms(uint16_t Times)` | 毫秒延时，最大可延时约 6.5 秒 |
| `Delay_us(uint16_t Times)` | 微秒延时 |

## 说明

内部使用 SysTick 定时器计数实现，延时会占用 CPU（软件阻塞方式），适合简单、非实时的场景。
