# 6-2 定时器外部时钟

定时器外部时钟计数实验：用外部脉冲作为定时器的计数时钟源。

## 功能

- 定时器 TIM2 以 **外部脉冲信号** 作为时钟（外部时钟模式）
- 外部每来一个脉冲，计数器 CNT 加 1
- 计数器溢出触发中断，`Num++`
- OLED 同时显示中断次数 `Num:` 和计数器当前值 `CNT:`

## 涉及知识点

- 定时器 **外部时钟** 模式（外部脉冲计数）
- 计数器寄存器 `TIM_GetCounter()` 读取
- 定时器更新中断

## 核心接口

| 函数 | 说明 |
|------|------|
| `Timer_Init()` | 初始化定时器为外部时钟模式 |
| `Timer_GetCounter()` | 读取当前计数器值 |

## 用途

可用来测量外部脉冲的频率或对脉冲计次，比改外部中断更高效，不占用 CPU。

## 源码大致逻辑

```c
while (1) {
    OLED_ShowNum(1, 5, Num, 5);            // 溢出次数
    OLED_ShowNum(2, 5, Timer_GetCounter(), 5); // 当前计数值
}
```

## 接线

| 外部脉冲源 | STM32 |
|-----------|-------|
| 信号 | TIM2 外部时钟引脚（见 Timer.h 配置） |
| GND | GND（共地） |
